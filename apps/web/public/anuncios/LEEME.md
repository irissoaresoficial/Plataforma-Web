# Los creativos de la campaña de Meta

Viven aquí, dentro de `public/`, por una razón muy concreta: **Meta los
descarga de una dirección pública**. Para montar un anuncio por su API hay
que darle una URL que sus servidores puedan abrir, y la web ya es eso.

La alternativa era subirlos a mano por el administrador de anuncios cada vez,
o montar un almacén aparte. Esto es gratis, ya está desplegado y queda
versionado junto al resto de la casa: el día que alguien pregunte «¿de dónde
salió este anuncio?», está aquí.

| Archivo | Medida | Para qué |
|---|---|---|
| `cartela-1x1.png` | 1080×1080 | Feed cuadrado |
| `cartela-4x5.png` | 1080×1350 | Feed vertical |
| `cartela-9x16.png` | 1080×1920 | Stories y Reels |
| `ponentes-1x1.png` | 1080×1080 | Quién da la clase |
| `idea-1x1.png` | 1080×1080 | La que explica el patrón |
| `idea-9x16.png` | 1080×1920 | La misma, vertical |

NO son decoración de la web: ninguna página las enseña. Si algún día se deja
de anunciar, esta carpeta entera se puede borrar.

Se dibujaron con `piezas.html` (tipografía y colores de MARCA.md, fotos reales
de `images/`). Para rehacerlas con otra fecha, se cambia el texto y se vuelven
a fotografiar: no se retocan a mano, que es como se acaba con seis piezas que
no dicen lo mismo.
